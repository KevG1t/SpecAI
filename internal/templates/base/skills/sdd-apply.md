# Skill: SDD Apply

This skill guides the AI agent through writing clean, SOLID, and tested code.

## Rules
- **Clean Diff:** Modify only what is necessary.
- **Maintain Style:** Follow existing patterns in the codebase (naming, formatting).
- **No Placeholders:** Write complete code, avoid `// TODO: implement later` inside production files.
- **Continuous Tracking:** Mark your progress in `task.md`.
